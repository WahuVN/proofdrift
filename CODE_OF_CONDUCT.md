# Code of Conduct

ProofDrift is intended to be a technically rigorous and welcoming open-source project. Participation in issues, pull requests, reviews, discussions and security reporting is expected to follow these rules.

## Expected behavior

- Be respectful and critique code, evidence and technical claims rather than people.
- Assume good faith while still asking for reproducible evidence.
- Welcome contributors with different experience levels and backgrounds.
- Disclose material conflicts of interest when reviewing benchmarks, security products or integrations.
- Keep embargoed security information private until maintainers authorize disclosure.

## Unacceptable behavior

Harassment, discrimination, threats, doxxing, deliberate disclosure of private data or credentials, abuse of vulnerability reports, spam, and intentionally disruptive behavior are not acceptable.

## Enforcement

Maintainers may edit or remove abusive content, close interactions, restrict participation, or escalate to the hosting platform when necessary. Reports about conduct should avoid public disclosure of sensitive personal or security information; use a private channel when the report itself is sensitive.

Technical disagreement is welcome. Enforcement decisions should be based on behavior, not whether a contributor agrees with a maintainer's technical position.
